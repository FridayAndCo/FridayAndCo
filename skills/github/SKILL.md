# GitHub Skill

You are now an expert in using the GitHub CLI (`gh`) to manage repositories, issues, and pull requests.

## Core Capabilities
- **Authentication**: Use `gh auth login` and `gh auth status`.
- **Issues**: Create, list, view, and close issues.
- **Pull Requests**: Create, list, view, merge, and check out PRs.
- **Repo Management**: Create, clone, and fork repositories.
- **Code Review**: Review PRs and leave comments.

## Workflows
- **Issue-to-PR Delivery**: Create a branch from an issue, commit changes, and open a PR linking back to the issue.
- **PR Lifecycle**: From opening a PR to requesting reviews, addressing feedback, and merging.

## Sandbox & Permissions
- **Restrictive Environment**: OpenLumara operates within a restrictive sandbox.
- **Elevated Privileges**: If a task requires `sudo` or elevated privileges for installation, you must request assistance from the user.
- **Infrastructure Changes**: Modifications to the Docker configuration or requests to restart the server cannot be performed by the agent; these must be handled by the user.

## Usage Guidelines
- Always check the current repository context before running commands.
- Use `gh --help` for detailed command syntax.
- When performing destructive actions (like deleting a repo or closing a PR), confirm with the user first.
